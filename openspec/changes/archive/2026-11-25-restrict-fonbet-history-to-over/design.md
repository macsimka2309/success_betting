# Design

## Context

Ночная обёртка проверяет полноту браузерного экспорта, вызывает импортёр и публикует его отчёт. Импортёр разбирает каждый купон, вызывает транзакционную сверку и возвращает код неполноты при записанных пропусках. Мониторинг реагирует на этот код и поля отчёта. Дата новых записей проверяется по дате приёма ставки в Москве.

## Goals / Non-Goals

**Цели.** Ограничить ночной импорт и его отчёт одиночными общими ТБ. Сохранить видимость реальных проблем с выгрузкой и подходящими ставками.

**Вне объёма.** Смена расписания, миграции, изменение нормализации расчёта ТБ, удаление ранее импортированных ставок и изменения в штатном расчёте ставок, ручном вводе и live-уведомлениях.

## Decisions

- Проверку полноты истории выполнять перед отбором. Отбор делать в импортёре перед полной валидацией купона и до передачи записей в SQL. Для отбора проверить одиночный тип, включая одиночный фрибет, один исход и признаки общего тотала с направлением «больше». ТМ, индивидуальные тоталы, экспрессы и остальные рынки исключать даже при повреждениях других полей купона.
- Сохранить раздельные результаты «купоны вне отбора» и «ошибка подходящего купона» внутри обработки. Для распознанного общего ТБ повреждённая линия, коэффициент, время или результат остаются ошибкой разбора. Отбор сам по себе не расширяет поддерживаемые форматы линий и результатов.
- Поле `found` считать по целевому дню и только по купонам, отнесённым к отбору. Исключённые рынки не увеличивают `found`, `freebet_count`, `skipped_count` и не попадают в `results` либо `skipped`. При полном экспорте и пустом отборе публиковать штатный успешный отчёт с нулевыми счётчиками. Оставить структуру отчёта совместимой с мониторингом.
- Для отобранных купонов переиспользовать существующий разбор статуса, даты, признака фрибета и транзакционную сверку с реестром. Сохранить привязку к существующим ставкам и дедупликацию по ID купона. Фильтр касается входа ночной сверки. Другие пути расчёта существующих записей продолжают действовать по своим правилам.

## Risks / Trade-offs

- Отчёт содержит только отобранные купоны, поэтому его объём может быть меньше числа купонов в личной истории Fonbet.
- Если исход нельзя распознать как общий ТБ, он не участвует в отчёте по ставкам. Неполный обход или отказ источника обнаруживается отдельно на этапе проверки экспорта.
