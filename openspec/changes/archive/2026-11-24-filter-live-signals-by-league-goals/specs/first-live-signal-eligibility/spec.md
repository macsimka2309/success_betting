# Spec Delta

## Purpose

Показывать результативность лиги как контекст футбольного сигнала и требовать подтверждённую статистику второго тайма для первого сообщения.

Точки проверки — [выбор снимка](../../../../../../src/jobs/alert_rules.py), [диспетчер](../../../../../../src/jobs/alert_dispatch.py) и [тесты диспетчера](../../../../../../tests/test_alert_dispatch.py).

## ADDED Requirements

### Requirement: Подтверждённые данные второго тайма

Для первого сигнала `half_pressure` система SHALL использовать пригодную статистику второго тайма одного источника. API-Football сохраняет приоритет. При отсутствии его пригодных данных допускается проверенная статистика Fonbet для того же матча.

#### Scenario: У API-Football есть только статистика всего матча

- **WHEN** API-Football вернул статистику всего матча, а Fonbet не дал пригодного снимка второго тайма
- **THEN** первый сигнал не отправляется

#### Scenario: Второй тайм доступен в Fonbet

- **WHEN** пригодный снимок второго тайма есть только у Fonbet и он однозначно относится к матчу
- **THEN** данные Fonbet участвуют в проверке действующего триггера

### Requirement: Справочная результативность лиги

Сигнал и напоминание SHALL показывать среднее число голов в основное время по завершённым матчам того же сезона лиги из локальной базы API-Football либо «нет данных». Показатель SHALL NOT менять условия отправки.

#### Scenario: Лига с результативностью ниже прежнего порога

- **WHEN** сработал триггер, а среднее по лиге равно 2,49
- **THEN** сигнал отправляется при выполнении остальных условий и показывает среднее 2,49

#### Scenario: Среднее неизвестно

- **WHEN** нет однозначной связи с сезоном лиги либо нет завершённых матчей с пригодным счётом
- **THEN** при выполнении остальных условий сообщение отправляется с отметкой «нет данных»

#### Scenario: Матч с дополнительным временем

- **WHEN** завершённый матч дошёл до дополнительного времени или серии пенальти
- **THEN** в расчёт входит только подтверждённый счёт основного времени

#### Scenario: Повтор сигнала

- **WHEN** выполнены действующие условия напоминания
- **THEN** напоминание отображает сохранённую результативность исходного сигнала, а допуск определяется действующими правилами повтора
