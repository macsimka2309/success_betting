# План реализации

Статусы: `[ ]` не начато, `[~]` выполняется, `[x]` завершено, `[!]` заблокировано.

## Этап 0. Согласование

- [ ] Заполнить контекст.
- [ ] Утвердить требования.
- [ ] Утвердить архитектуру и модель данных.
- [ ] Утвердить требования безопасности и инфраструктуру.

## Этап 1. Безопасный аудит сервера

- [ ] Проверить ОС, CPU, RAM, диски и время.
- [ ] Проверить порты, firewall и SSH без изменений.
- [ ] Проверить Docker, контейнеры, службы и reverse proxy.
- [ ] Проверить существующие БД, каталоги и backup.
- [ ] Сопоставить результат с `docs/04-инфраструктура.md`.
- [ ] Представить план изменений и получить одобрение.

## Этап 2. Инфраструктура

- [ ] Настроить Docker и Compose при необходимости.
- [ ] Создать внутреннюю сеть.
- [ ] Настроить persistent storage и права.
- [ ] Настроить лимиты ресурсов и health checks.
- [ ] Подготовить проверяемый rollback.

## Этап 3. PostgreSQL

- [ ] Развернуть согласованную версию.
- [ ] Создать БД и пользователя приложения.
- [ ] Настроить минимальные права и сетевой доступ.
- [ ] Применить миграции.
- [ ] Проверить подключение и перезапуск.

## Этап 4. Резервное копирование

- [ ] Настроить автоматический backup и retention.
- [ ] Хранить копии отдельно от основного диска.
- [ ] Настроить контроль успешности.
- [ ] Провести и задокументировать тестовое восстановление.

## Этап 5. Безопасность

- [ ] Проверить firewall, SSH и публичную доступность БД.
- [ ] Проверить хранение и ротацию секретов.
- [ ] Проверить пользователей, права и журналы.

## Этап 6. Мониторинг

- [ ] CPU, RAM, диск и доступность сервисов.
- [ ] PostgreSQL: подключения, блокировки, место и медленные запросы.
- [ ] Backup: успешность и давность последней копии.
- [ ] Настроить полезные оповещения.

## Этап 7. Итоговая проверка

- [ ] Запустить тесты, линтер и сборку.
- [ ] Проверить миграции и обратную совместимость.
- [ ] Выполнить контролируемую перезагрузку в согласованное окно.
- [ ] Убедиться, что сервисы поднялись автоматически.
- [ ] Проверить приложение и восстановление из backup.
- [ ] Провести аудит соответствия спецификации.
