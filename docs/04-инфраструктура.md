## Firewall

Документировать фактически разрешённые порты. Типично: 22 для SSH, 80/443 для web. До изменения правил убедиться, что текущая SSH-сессия не будет потеряна.

## SSH

- вход по ключам;
- отдельный пользователь с минимально необходимым `sudo`;
- отключение root/password выполнять только после проверки альтернативного входа;
- порядок ротации ключей.
