# Очередь истории континентальных клубных турниров

Поручение владельца 03.11.2026: прошлые сезоны 19 включённых турниров.
Горизонт соответствует утверждённому backfill: с 2018 года.

Очередь определяется каталогом league_seasons: выбранные league_id,
is_tracked=true, сезон >=2018, end_date раньше сегодня минус 7 дней.
Порядок — от новых к старым. Успех каждой пары лига/сезон записывается
в collection_runs как historical_fixtures_<league>_<season>. Успешные пары
повторно не запрашиваются; ошибки и исчерпанный бюджет не закрывают очередь.
Пустой список матчей считается ошибкой и остаётся для повторной проверки.

Обработка встроена в существующий international-backfill (10:00 МСК),
использует его бюджет 300 запросов, затем продолжает прежнюю международную
дозагрузку на остатке. Схема БД и суточные потолки не меняются. Списки матчей
пишутся существующим upsert, повтор после сбоя безопасен. Общая историческая
очередь daily подбирает их события, статистику, составы и таймы с учётом coverage.
Исторические коэффициенты этим способом не восстанавливаются.

Проверки: завершённая пара пропускается, пустой ответ/ошибка остаются в очереди,
бюджет ограничивает запросы, данные повторно не дублируются. Запуск по расписанию
начиная с 04.11.2026; текущий daily вручную не перезапускается.

Установлено в production 03.11.2026. Дополнительная граница — season не выше
текущего года: каталог содержит несовместимые с годом даты у будущих сезонов.
Проверки: 17 тестов прошли; точный SQL отбора выполнен read-only на production;
импорт нового обработчика проверен Python 3.12. Прежний collect.py сохранён в
