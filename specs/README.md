# Спецификации функций

Каждая существенная функция получает отдельный файл. Рекомендуемое имя: `NNN-краткое-название.md`.

## Обязательная структура

1. Статус и владелец решения.
2. Цель и границы.
3. Пользовательские сценарии.
4. Функциональные требования с идентификаторами.
5. Бизнес-правила.
6. Модель данных.
7. API или интерфейсы.
8. Ошибки и крайние случаи.
9. Безопасность.
10. Критерии приёмки.
11. Тестовые сценарии.
12. Связь с требованиями и ADR.

Используйте `авторизация.md` как пример. Реализация начинается только после утверждения спецификации.
