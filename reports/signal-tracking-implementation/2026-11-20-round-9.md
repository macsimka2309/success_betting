# Приёмка исправлений девятого раунда

Исправления `add-alert-reminder-and-post-signal-goals` проверены на одноразовом PostgreSQL 16. Тесты используют подменённые ответы спортивных источников и доставку Telegram. Используется действующая схема 036. [Отчёт о дефектах](../signal-tracking-review-round-9-2026-11-20/review.md)

| Последовательность | Результат |
|---|---|
| Пенальти → неполный ответ с другим типом → финальный протокол с двумя голами → повтор протокола | Спорная строка сохраняет кандидата. Исходный гол сохраняет тип и ревизию до подтверждения. Пенальти получает счёт 2:0 на прежнем ID, гол с игры получает отдельный ID |
| Неполный ответ с отсутствующим типом или с однозначным ID источника | При отсутствии типа сохраняется известное значение. Подтверждённый ID позволяет уточнить тип на прежней записи |
| Снимок Fonbet → прямое или последовательное объединение алиасов → повтор | Возвращается первый архивный ID. Ревизия, ссылка гола и число записей сохраняются |
| Повтор при исторических копиях → новое содержимое или другой ID события источника с тем же временем | Повтор возвращает самый ранний совпавший ID с сохранением архива. Отличающийся снимок получает отдельный ID |

Оба воспроизведения перенесены в основной набор. [Тесты результатов](../../tests/test_signal_results.py) · [Тесты истории голов](../../tests/test_signal_goal_store.py) · [Модель данных](../../docs/data-model.md) · [Инструкция выпуска](../../deploy/README-signal-tracking.md)
