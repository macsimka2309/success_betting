# Приёмка исправлений пятого раунда

Проверка `add-alert-reminder-and-post-signal-goals` выполнена на одноразовом PostgreSQL 16. Данные источников и доставка Telegram в тестах подменены. [Отчёт о дефектах](../signal-tracking-review-round-5-2026-11-20/review.md)

| Сценарий | Результат |
|---|---|
| Финальный таймлайн добавляет гол на 88-й минуте и сдвигает счёт двух голов на 90+2 | Пенальти и гол с игры сохраняют свои ID и типы. Только гол на 88-й получает новый ID. Суточный повтор оставляет три активных события и сохраняет версии счёта |
| У голов с изменившимся счётом нет однозначного соответствия | Прежние ID, счёт и активность сохраняются. В pending записываются кандидаты. Повтор того же наблюдения сохраняет число версий и записей pending |
| Последний ответ API перед запросом архивной статистики без явной связи дублирует матч, пропускает его или содержит другую команду | Напоминание остаётся в ожидании, первое решение не записывается. Следующий пригодный опрос может запустить единственное напоминание |
| Есть явная связь либо новое наблюдение завершилось после начала запроса статистики | Пригодная архивная пара участвует в решении. При нескольких допустимых связях без явной привязки неоднозначность сохраняется |

Оба исходных сценария перенесены в `tests/test_signal_results.py` и `tests/test_signal_reminders.py`. Для исправлений используется существующая схема 036. [Модель данных](../../docs/data-model.md) · [Инструкция выпуска](../../deploy/README-signal-tracking.md)
