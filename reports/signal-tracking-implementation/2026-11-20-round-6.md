# Приёмка исправлений шестого раунда

Исправления `add-alert-reminder-and-post-signal-goals` проверены на одноразовом PostgreSQL 16. Тесты используют подменённые ответы спортивных источников и доставку Telegram. Для реализации используется действующая схема 036. [Отчёт о дефектах](../signal-tracking-review-round-6-2026-11-20/review.md)

| Сценарий | Результат |
|---|---|
| После обновления списка API содержит дубликат матча, а сборщик сохраняет положительный снимок 75 | Снимок остаётся доступен для анализа. Диспетчер ждёт проверенной пары. При наличии первого положительного решения оно сохраняется |
| Следующий штатный опрос имеет проверяемую ссылку только в снимке 75 | Диспетчер проверяет исходную пару и доставляет один повтор. Проверка использует локальный архив |
| На 90+2 добавлен пенальти перед уже известным голом с игры | ID гола с игры сохраняется при переходе со счёта 1:0 на 2:0. Пенальти получает отдельный ID. Live- и финальная сверка сохраняют две записи и версии |
| Один из двух голов на 90+2 может относиться к 88-й минуте | Оба известных гола остаются активными, возможная коррекция сохраняется с кандидатами. Отдельный гол другой команды записывается. После подтверждения связи изменяется минута на прежнем ID |

Три сценария добавлены в основной набор. [Тесты напоминаний](../../tests/test_signal_reminders.py) · [Тесты результатов](../../tests/test_signal_results.py) · [Модель данных](../../docs/data-model.md) · [Инструкция выпуска](../../deploy/README-signal-tracking.md)
