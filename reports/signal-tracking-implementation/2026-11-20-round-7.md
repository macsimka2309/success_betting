# Приёмка исправлений седьмого раунда

Исправления `add-alert-reminder-and-post-signal-goals` проверены на одноразовом PostgreSQL 16. Тесты используют подменённые ответы спортивных источников и доставку Telegram. Используется действующая схема 036. [Отчёт о дефектах](../signal-tracking-review-round-7-2026-11-20/review.md)

| Сценарий | Результат |
|---|---|
| После проверенной статистики на 73-й текущий ответ того же запуска дублирует матч на 75-й или 76-й минуте либо показывает статус FT в одной из строк | Первое решение остаётся связано с проверенным опросом. Напоминание продолжает ожидать, попытка доставки не записывается |
| Текущий ответ однозначен либо срок ожидания истёк | В пределах окна пригодный опрос разрешает один повтор. Достоверный выход из окна, подтверждённый конец или истечение срока закрывают ожидание. Пригодный контекст того же запуска сохраняет возможность отправки |
| Неоднозначный ответ поступил после отбора напоминания либо относится к API-алиасу матча Fonbet | Диспетчер повторно проверяет данные перед отправкой. Для закрытия по статусу алиаса требуется однозначный ответ |
| Протокол добавляет гол на 69-й и сохраняет известный гол на 70-й, при этом возможен перенос позднего гола | Прежний ID на 70-й получает версию со счётом 1:1, а гол на 69-й сохраняется отдельно. Поздние голы остаются на сверке с кандидатами. Повтор наблюдения сохраняет число записей и версий |
| При тех же событиях ответ неполный и счёт конфликтует | Прежняя версия остаётся активной. Список кандидатов включает гол с совпавшей отметкой времени |

Три новых сценария добавлены в основной набор. [Тесты напоминаний](../../tests/test_signal_reminders.py) · [Тесты результатов](../../tests/test_signal_results.py) · [Модель данных](../../docs/data-model.md) · [Инструкция выпуска](../../deploy/README-signal-tracking.md)
