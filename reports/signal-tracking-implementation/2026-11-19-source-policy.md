# Локальная приёмка раздельного наблюдения после сигнала

Окружение проверки включает одноразовый PostgreSQL 16 и Chromium с обезличенными спортивными фикстурами. Telegram и API-Football заменены подставными ответами в сценариях доставки и сбора. Выпуск, миграции и активация флагов на сервере остаются отдельной операцией.

| Проверка | Результат |
|---|---|
| Регрессии сигнала, напоминаний, событий, итогов и штатного сбора | 337 прошли, один прежний тест меню исключён |
| Контроль отмены матча, диагностики и независимости от API после последних правок | 4 прошли |
| Node и Chromium | 40 прошли. Проверены концовка 90+12 и чтение архивной карточки при её наличии |
| Импортер Fonbet | 17 прошли |
| Полный pytest на финальном коде | 961 прошли, 2 пропущены, 3 прежних сбоя |
| OpenSpec strict, синтаксис Bash и Node, проверка пробелов Git | Прошли |

Три сбоя полного набора отдельно воспроизведены на схеме 001–034:

- `test_alert_outcomes.py::test_menu_has_hit_rate_button`
- `test_live_alerts_favorite.py::test_alert_comes_with_four_bet_buttons`
- `test_live_alerts_favorite.py::test_two_features_in_one_run_give_one_card_and_dedupe_both`

| Дефект повторного review | Проверка текущего поведения |
|---|---|
| Частичный ответ возвращал отменённый VAR гол | Гол остаётся неактивным до более свежего полного снимка. История и исходный ID сохранены |
| Частичный автогол создавал дубль | При однозначной идентичности сохраняются ID и зачтённая сторона. Иначе наблюдение остаётся в pending |
| Результат 0:1 и таймлайн 7:0 считались согласованными | Конец матча фиксируется отдельно. Список помечается неполным с причиной расхождения |
| Пустой API закрывал обработку сопоставленного матча | Fonbet-очередь выполняет чтение по закреплённому ID |
| Исчерпание API блокировало матч только из Fonbet | Проверка идёт по доступности браузера. API-запрос отсутствует |

Версия 2 выбирает режим по первому подтверждённому сообщению. Проверены обе очередности merge и объединение во время браузерного чтения. Повтор требует свежей статистики исходного источника в 65–75. При отсутствии данных ожидание ограничено 20 минутами от первого подтверждения Telegram. Этот предел относится к напоминанию. Fonbet продолжает работать независимо.

Проверены сохранение последнего live-снимка, ротация на одном браузерном слоте, рестарт, исчезновение без ложного окончания, FT, ET и отмена. После простоя выполняется один актуальный опрос, затем сохраняются оставшиеся суточные проверки. Занятая блокировка и внутренний перенос не списывают проверку.

Первый тест HTTP-редиректа вышел из подменённого маршрута на публичную страницу Fonbet в отдельном Chromium без пользовательского профиля. Повторная проверка использовала локальную имитацию перехода.

Стенд подтверждает разбор размеченных результатов и переход к архивной карточке с совпавшим ID. Доступность «Хода матча» и независимой разбивки счёта на реальной карточке после завершения зависит от Fonbet. Проверка Linux unit-файлов и запрос реального спортивного матча входят в процедуру отдельного выпуска. [Процедура выпуска](../../deploy/README-signal-tracking.md)
