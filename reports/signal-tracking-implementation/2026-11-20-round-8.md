# Приёмка исправлений восьмого раунда

Исправления `add-alert-reminder-and-post-signal-goals` проверены на одноразовом PostgreSQL 16. Тесты используют подменённые ответы спортивных источников и доставку Telegram. Используется действующая схема 036. [Отчёт о дефектах](../signal-tracking-review-round-8-2026-11-20/review.md)

| Последовательность | Результат |
|---|---|
| Исходный сигнал → проверенный опрос на 73-й → ответ с другими командами на 76-й или при FT → подтверждённый ответ | Первое решение сохраняется. Несовместимый ответ оставляет ожидание, а проверенный выход из окна или FT закрывает его. Статистика с несовместимыми командами не участвует в решении и доставке |
| Два гола на 90+2 → финальный протокол с более ранним голом соперника и конфликтом типа → повтор → подтверждённая связь | Пенальти получает счёт 1:1 на прежнем ID, ранний гол записывается отдельно. Автогол остаётся на сверке с кандидатом. После подтверждения типа в записи с прежним ID отражается автогол |
| Live-снимок → более свежая коррекция со спорной частью → повтор прежней записи и запоздавший ответ → подтверждённый итог | После старого снимка сохраняются счёт, активность, ревизия и ссылка на действующее наблюдение. Подтверждённый итог продолжает историю на тех же ID |
| Гол → отмена VAR с тем же временем наблюдения → повтор и старый ответ → восстановление | Равное время разрешается по архивному ID. Активность и действующая версия сохраняются после повторов. Новое восстановление добавляет запись в историю |
