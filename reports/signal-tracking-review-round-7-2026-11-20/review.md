# Проверка исправлений шестого раунда

Все 11 воспроизведений раундов 3–6 прошли. Три дополнительных случая выявили два дефекта. [Воспроизведения](repro_cases.py)

1. **P1. Дубликат в текущем контексте API управляет доставкой и отменой.** Штатный сборщик получает проверенную положительную статистику матча на 73-й минуте. При обработке другого матча тот же запуск обновляет live-список, где первый матч указан дважды. Если последняя строка показывает 75-ю минуту, диспетчер отправляет повтор, связывая свежий контекст со статистикой по общему `run_id`. Если та же строка показывает 76-ю минуту, диспетчер закрывает напоминание как `outside_window`. При неоднозначном актуальном контексте проверенное первое решение на 73-й минуте должно сохраняться, а напоминание должно ждать пригодного штатного опроса в действующем окне. [Сопоставление по запуску](../../src/jobs/signal_reminders.py#L16) · [Проверка выхода из окна](../../src/jobs/signal_reminders.py#L33)
2. **P2. Спорные голы на 90+2 блокируют сопоставление известного гола на 70-й.** После добавления пропущенного гола соперника на 69-й счёт уже известного гола на 70-й меняется с 1:0 на 1:1. Одновременно один из двух поздних голов может быть перенесён на 88-ю. Код добавляет для гола на 70-й кандидатов только из спорной поздней группы и пропускает прежний гол на той же отметке с тем же типом. В активной записи остаётся счёт 1:0. Однозначное совпадение на 70-й должно быть учтено до расширения списка спорных переносов. [Поиск спорных связей](../../src/jobs/signal_goal_store.py#L163)
